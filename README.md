# SatuPadu

Undangan digital pernikahan. Satu undangan, dipadu untuk setiap tamu.

Website statis satu file (`index.html`): landing & harga, katalog tema, builder undangan dengan pratinjau langsung, undangan tamu, dashboard pasangan (grup, sesi, import Excel), akun & checkout, serta QR check-in hari H.

Status: prototype. Pembayaran, OTP, dan login Google masih simulasi; data tersimpan di browser pengguna.
